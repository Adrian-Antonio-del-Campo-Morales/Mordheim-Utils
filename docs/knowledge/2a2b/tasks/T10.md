# T10 — Automatización de campaña Web

## Inicio y coordinación

- Pertenece a la fase 2. La implementación empieza tras aceptar T09.
- Puede ejecutarse en paralelo con T11 únicamente con archivos disjuntos y contratos T09 congelados.
- Usa solo las obligaciones de campaña clasificadas como `Warband Manager Web` por T06.
- Core, loaders, modelos, bindings y esquemas compartidos tienen un único propietario; cualquier ampliación se coordina antes de escribir.

## Objetivo

Automatizar en los servicios y dominio existentes los efectos 2A/2B aplicables a creación, reclutamiento, equipo, mercenarios, mantenimiento, experiencia, avances, exploración y posbatalla que consume `warband-manager-web`. No duplicar reglas en React ni desarrollar comportamiento del Combat Simulator.

## Pasos

- [ ] Extraer de T06 los IDs, fuentes, condiciones, decisiones y criterios de campaña Web.
- [ ] Trazar cada flujo real en Python/TypeScript y confirmar cuál es consumido por Web antes de editar.
- [ ] Reutilizar comandos, eventos, decisiones pendientes, ledgers y serialización existentes.
- [ ] Añadir soporte común solo cuando la obligación no pueda expresarse mediante los mecanismos actuales.
- [ ] Mantener validación en servicio/dominio y errores tipados/localizables para T11.
- [ ] Preservar orden de decisiones, dados y estado; inyectar RNG donde ya exista el patrón.
- [ ] Separar del mismo registro cualquier efecto exclusivo de combate y remitirlo a T13.
- [ ] Conservar compatibilidad de campañas anteriores y realizar migración solo si el formato persistido lo exige.
- [ ] Probar éxito, rechazo, ausencia del efecto, persistencia/reapertura y una composición por mecanismo modificado.
- [ ] Entregar a T11 las entradas, resultados, errores y estados pendientes/históricos que debe presentar.
- [ ] Ejecutar las suites enfocadas de campaña Python/TypeScript; no interpretar helpers aislados como flujo completo.

## Fin y evidencia

Cada obligación de campaña Web asignada tiene comportamiento observable, persistencia y prueba de servicio/dominio; campañas anteriores siguen cargando; T11 dispone de contratos y errores estables. Ninguna obligación de combate se marca como cubierta por esta tarea.
