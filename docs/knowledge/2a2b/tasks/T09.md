# T09 — Construcción, selección y contratos para Web

## Inicio y coordinación

- Abre la fase 2 después del commit local de T08.
- Usa las obligaciones `Warband Manager Web` de T06. T10 y T11 pueden leer, pero no escribir contratos compartidos hasta aceptar T09.
- Propiedad candidata: construcción de roster, selección, restricciones, contratos/modelos y bindings mínimos. Cada archivo compartido requiere asignación explícita.

## Objetivo

Compilar y seleccionar correctamente perfiles y opciones 2A/2B para los flujos reales de `warband-manager-web`: límites, equipo, restricciones, decisiones iniciales y concesiones de reglas/habilidades. Fijar las interfaces que consumirán campaña e interfaz antes de paralelizar T10/T11.

## Pasos

- [ ] Extraer de T06 todos los efectos de construcción y selección destinados a Web.
- [ ] Trazar YAML → loader → compilador/dominio → servicio TypeScript → consumidor Web.
- [ ] Identificar y estabilizar primero contratos compartidos, entradas, resultados y errores.
- [ ] Demostrar cada carencia con un caso mínimo en las suites existentes.
- [ ] Reutilizar bindings y mecanismos actuales; ampliar la capa común solo cuando no pueda expresar la fuente.
- [ ] Aplicar destinatario, condición, opciones exclusivas, límites y excepciones correctos.
- [ ] Evitar doble concesión entre reglas automáticas y habilidades seleccionadas.
- [ ] Validar restricciones en dominio/servicio, no solo deshabilitando controles React.
- [ ] Asegurar que cada elección necesaria llega a persistencia y tiene una representación estable para T11.
- [ ] Probar límites, selección válida/inválida, ausencia de regla y una interacción por mecanismo modificado.
- [ ] Ejecutar las suites enfocadas de construcción y campaña afectadas y la verificación estructural.
- [ ] Entregar contrato final y liberar archivos antes de autorizar escritura paralela de T10/T11.

## Fin y evidencia

Cada obligación de construcción/selección produce resultado correcto o rechazo explícito; cada banda permitida tiene al menos una selección válida cuando la fuente lo permite; contratos, errores y persistencia están fijados. T10 y T11 pueden iniciar con archivos disjuntos.
