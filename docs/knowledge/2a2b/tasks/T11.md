# T11 — Interfaz web y escritorio para 2A/2B

## Objetivo e inicio
Exponer las bandas y todas las interacciones necesarias para las reglas automatizadas de 2A/2B en las aplicaciones existentes, con textos ES/EN y accesibilidad. Leer [contrato de coordinación](../README.md), T07, T08 y T10 antes de actuar. Base documental: 9118ca2; comprobar el checkout real al iniciar.

Dependencia de inicio: T07 cerrado y contrato de datos acordado. La selección de categorías puede avanzar en paralelo a T08. La interfaz de decisiones depende de lo entregado por T08 y de la automatización de campaña de T10: no cerrar T11 antes de T10. Retener staging; no publicar ni hacer push.

## Propiedad y límites
Propiedad: ProductApp.tsx, etiquetas de interfaz, componentes web afectados, diálogos de escritorio afectados y sus pruebas de presentación. Coordinar cualquier edición de contratos/servicios con T08/T10; no duplicar lógica de reglas en React o Tk. Solo el coordinador actualiza el documento principal.

Reutilizar selector, formularios, progreso, traducciones, presentationOutput y adaptadores existentes. No añadir plataformas ni bibliotecas. Acordar archivos compartidos antes de editarlos.

- [ ] Inspeccionar estado Git y cambios concurrentes; leer los contratos actuales de presentación y reglas afectadas.
