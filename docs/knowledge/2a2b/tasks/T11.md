# T11 — Interfaz Warband Manager Web

## Inicio y coordinación

- Pertenece a la fase 2. Puede preparar categorías tras T09 y trabajar en paralelo con T10 usando archivos disjuntos.
- No cierra hasta aceptar T10 y conectar todos sus contratos de campaña.
- La aplicación de escritorio ya no existe y queda fuera de alcance. No crear ni modificar diálogos Tk ni exigir paridad con escritorio.
- Propiedad candidata: `apps/warband-manager-web`, presentación compartida imprescindible y pruebas Web asignadas.

## Objetivo

Hacer utilizables las bandas 2A/2B en `warband-manager-web`: selección de categorías, construcción, campaña, decisiones, persistencia, ES/EN, accesibilidad, errores y exportación PDF. La interfaz consume T09/T10 y no implementa reglas dentro de componentes React.

## Pasos

- [ ] Confirmar que el lector/generado Web expone grados 2A/2B y ampliar filtros dinámicos sin listas duplicadas.
- [ ] Conectar cada elección de T09 y cada comando/estado de T10 al flujo existente.
- [ ] Mantener validación de dominio como autoridad; la UI explica y previene errores sin sustituirla.
- [ ] Resolver nombres, reglas, objetos y estados mediante los mecanismos de presentación existentes, sin filtrar IDs técnicos.
- [ ] Cubrir ES/EN en controles, tablas, tooltips, errores, estados pendientes/históricos y PDF.
- [ ] Añadir nombres accesibles, navegación por teclado, foco y estados deshabilitados explicables.
- [ ] Persistir y reabrir todas las nuevas elecciones; verificar también una campaña anterior.
- [ ] Probar rutas reales de producto: crear banda, reclutar/equipar, ejecutar decisiones de campaña, guardar, reabrir y exportar.
- [ ] Usar pruebas renderizadas y, cuando sea posible, navegador real; declarar lo que JSDOM no demuestra.
- [ ] Entregar escenarios completos y archivos liberados a T12.

## Fin y evidencia

Todas las obligaciones de interfaz de T09/T10 tienen flujo Web completo; las categorías 2A/2B se pueden incluir o excluir; persistencia, ES/EN, accesibilidad, errores y PDF están comprobados. No quedan referencias funcionales a una aplicación de escritorio.
