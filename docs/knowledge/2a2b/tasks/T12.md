# T12 — Generación de artefactos y actualización de evidencias

## Objetivo e inicio
Obtener artefactos reproducibles de la KB integrada y evidencias/manifiestos coherentes con las implementaciones terminadas. Leer [contrato de coordinación](../README.md). Dependencias: T09, T10 y T11 cerrados. Base documental 9118ca2; verificar estado real antes de operar.

## Propiedad y límites
Propiedad: generación final, outputs derivados y actualizaciones justificadas de digests/manifiestos. Un único agente genera durante esta tarea; evitar carreras de escritura con otros agentes. No modificar datos para esconder errores ni regenerar expectativas semánticas a ciegas. Mantener sources/2A y sources/2B. Solo el coordinador actualiza el documento principal. Sin push.

## Pasos
- [ ] Comprobar entregas T09/T10/T11 y ausencia de escritores activos sobre KB, contratos o reglas.
- [ ] Leer el generador actual y confirmar salidas: outputs/web-public/knowledge/knowledge-web.json, rules-prose.json y display-text.json. No editar estas salidas a mano.
- [ ] Generar mediante herramientas existentes y exigir cobertura de traducciones.
- [ ] Revisar digests obsoletos: distinguir cambio editorial de cambio semántico. Para el segundo, exigir que T09/T10 hayan revisado interpretación, casos y resultados antes de refrescar el digest.
- [ ] Regenerar el manifiesto de pruebas desktop/web cuando cambiaron las pruebas; revisar disposiciones y referencias, sin clasificar nuevas obligaciones como exclusiones para conseguir verde.
- [ ] Comparar conteos e IDs del artefacto con inventario de promoción acordado, conservando los registros anteriores y referencias de partidas guardadas.
- [ ] Ejecutar comprobación de frescura y determinismo; registrar tamaños y diferencias relevantes. Entregar la misma revisión y salidas a T13 y T14.

## Comandos existentes
Desde la raíz:
```powershell
python tools/knowledge/generate_knowledge_web.py --check-translations
python tools/verification/refresh_spec_digests.py --check
python tools/verification/make_test_manifest.py
python tools/knowledge/generate_knowledge_web.py --check --check-translations
```
Si los digests cambiaron y su revisión está documentada:
```powershell
python tools/verification/refresh_spec_digests.py
python tools/verification/refresh_spec_digests.py --check
```
make_test_manifest escribe outputs/parity/test-manifests/campaign-test-manifest.json. Confirmar la configuración actual antes de mover o versionar outputs ignorados. No forzar su inclusión en Git.

## Fin y evidencia
- [ ] Tres artefactos generados por la KB canónica, traducciones completas y comprobación de frescura exitosa.
- [ ] Digests y manifiesto coherentes; ningún cambio semántico aceptado por regeneración mecánica.
- [ ] Inventario esperado y obtenido reconciliados; staging conservado.
Guardar comandos, códigos de salida, revisión de entrada, salidas generadas y justificación de cada actualización editorial. Si falla la generación, devolver el defecto al propietario y repetir solo tras corregirlo.
