# T12 — Artefactos, validación Web y cierre

## Inicio y coordinación

- Cierra la fase 2 después de aceptar T10 y T11.
- Un único propietario genera artefactos y manifiestos. Reparaciones funcionales vuelven a T09, T10 o T11 y solo después se repite la evidencia invalidada.
- El coordinador mantiene la checklist y crea el commit local de fase 2. Sin push ni despliegue.

## Objetivo

Generar los artefactos Web desde la KB canónica y demostrar que 2A/2B funcionan de extremo a extremo en `warband-manager-web`, incluida automatización de campaña. Este cierre no valida todavía Combat Simulator.

## Pasos

- [ ] Comprobar que T09–T11 están aceptadas y no quedan escritores activos sobre KB, contratos o Web.
- [ ] Generar `knowledge-web.json`, `rules-prose.json` y `display-text.json` mediante la herramienta existente; no editarlos a mano.
- [ ] Exigir cobertura de traducciones y comparar inventario/IDs con la fase 1.
- [ ] Actualizar manifiestos Web solo si sus pruebas cambiaron; no regenerar digests semánticos de combate.
- [ ] Verificar frescura y determinismo de los generados.
- [ ] Ejecutar suites de conocimiento necesarias, campaña Python/TypeScript, Web, typecheck, build y presentación.
- [ ] Ejecutar escenarios representativos 2A/2B: crear, operar, guardar, reabrir, continuar y exportar PDF.
- [ ] Verificar una campaña anterior, ES/EN, nombres accesibles, teclado, errores y ausencia de IDs técnicos visibles.
- [ ] Registrar por separado pruebas automatizadas, navegador real y revisión del PDF.
- [ ] Reconciliar todas las obligaciones `Warband Manager Web` de T06; ninguna puede cerrarse solo por aparecer en YAML.
- [ ] Tras aceptación, actualizar la checklist y crear el commit local de fase 2. No hacer push.

## Comandos de referencia

```powershell
python tools/knowledge/generate_knowledge_web.py --check-translations
python tools/knowledge/generate_knowledge_web.py --check --check-translations
python tools/mordheim-utils.py tests --scope campaign -q
npm --prefix packages/typescript test
npm --prefix apps/warband-manager-web test
npm --prefix apps/warband-manager-web run typecheck
npm --prefix apps/warband-manager-web run build
python tools/mordheim-utils.py check-presentation
```

Confirmar scripts y argumentos actuales antes de ejecutar.

## Fin y evidencia

Los artefactos son reproducibles, todas las obligaciones Web están cubiertas, los flujos completos y campañas anteriores funcionan, y traducciones/accesibilidad/PDF están verificados. El coordinador registra el commit local de fase 2 y abre la fase 3.
