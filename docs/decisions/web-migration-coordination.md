# Web migration coordination

Temporary collision avoidance for people and agents working on the web port. This is a live board, not a history log.

## Protocol

1. Before editing, add one row with the exact paths or narrow area you will touch.
2. Do not edit an overlapping path while another row is `active`; coordinate or choose other work.
3. On completion, change the row to `ready` with the commit if one exists, or remove it after integration.
4. A stale row may be removed after confirming its worker is no longer active.
