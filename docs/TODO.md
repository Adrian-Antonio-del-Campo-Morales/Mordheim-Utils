# Project backlog

This file lists durable, project-level gaps. Live counts and affected records
belong to executable inventories, YAML markers and generated reports, not to
this page.

## Combat and verification

- Replace transitional `compiler` bindings with shared `mechanic` or `trait`
  bindings where the semantics are truly equivalent.
- Complete pending semantic specifications and required interactions reported
  by `python tools/mordheim-utils.py verify --inventory`.
- Keep NumPy and native candidates certified against the modular oracle before
  relying on them.

## Deferred product scope

The current duel runtime deliberately excludes these domains. Implement them
only after approving a scope change in `registry/runtime-scope.yaml`:

- psychology and warband-wide proximity effects;
- shooting and missile weapons;
- movement, terrain and falling;
- magic in battle;
- mounts and ridden combat;
- scenario table mechanics beyond progression rewards.

## Knowledge gaps

- Resolve hireling `unresolved_references` as canonical skill, prayer, rune,
  equipment, mount, companion or procedure catalogues become available.
- Define composite-entity schemas before admitting multi-warrior, mounted or
  multi-persona Dramatis Personae to the hiring catalogue.
- Review the live Trading Post price-difference queue generated by
  `python tools/knowledge/maintenance/price-collation.py`.
- Make each intentionally unsupported item-to-engine mapping explicit.
- Complete missing interface translations and remove unused message keys.
